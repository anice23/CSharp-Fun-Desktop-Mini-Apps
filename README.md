# 🎮 C# Fun Games & Mini Desktop Apps

A collection of entertaining mini-projects and desktop applications built using C# to practice logic, problem-solving, and user interface handling.

## 🕹️ Featured Projects
* **Tic-Tac-Toe Game:** Classic interactive game with smart winning logic and turn management.
* **Pizza Order System:** Clean UI/Logic application handling user choices, pricing, and orders.

## 🛠️ Concepts Applied
* Conditional statements & Loops
* Functions & Modular code
* Event handling & State management
